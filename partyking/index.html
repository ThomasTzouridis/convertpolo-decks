Two tests we would run first on Partyking

TEST 01

Theme first discovery

Hypothesis
Visitors who arrive with a party theme buy more when every piece of that theme sits on one page.
Change
Theme pages that bundle costume, decoration and tableware, linked from the homepage and search.
Measured by
Revenue per visitor against a live control.
TEST 02

Paid traffic landing pages

Hypothesis
A bought visit converts better when the page matches the search it came from.
Change
Landing pages matched to the main paid search themes instead of the generic category page.
Measured by
Conversion rate of paid sessions against a live control.

Every change runs against a live control. Winners stay, losers get written down.
